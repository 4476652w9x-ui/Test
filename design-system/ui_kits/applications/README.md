# Applications — Newsletter & LinkedIn (derived templates)

These are **on-system proposals**, not recreations of an existing design — Scenario Three's newsletter and social presence are planned, so there is no production source to copy. They apply the live `stevengreen.com.au` system (Cabinet Grotesk + Satoshi, forest/sage, large radii, two-tone headlines, sage-underlined cap-titles) to two channels named in the brand brief.

- `newsletter.html` — a weekly issue email body (640px column): masthead wordmark, issue meta, two-tone headline, Satoshi long-form, a sage-underlined section label, a tabular figure pull-box, a pull-quote, and a subscribe/footer.
- `newsletter-issue.html` — a **full long-form issue** ("The rate card is honest. The margin isn't.") demonstrating the system end-to-end: two-tone masthead headline, TL;DR + numbered-takeaways card, scope/"next week" asides, pull-quotes, framework section headings, and **three on-brand financial diagrams built in CSS** — a segmented timesheet bar, an 8h-vs-10h utilisation comparison, and a monthly engagement-P&L card with a recoverability trend. (These double as the brand's financial-diagram patterns.)
- `linkedin.html` — three 1080×1080 card formats (scaled for preview): a forest quote card, a white stat card, and a sage-tint "seven decisions" index card.

Both pull tokens from the root `colors_and_type.css`. Treat copy as placeholder.
