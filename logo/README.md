# Scuderia Verde — Brand Marks

A logo system for **Scuderia Verde**, a turnkey sim-racing installer serving
high-net-worth clients in Australia.

## Files

| File | Use |
| --- | --- |
| `scuderia-verde-badge.svg` | Primary crest. Use for hero placements, embroidery, plaques, vehicle livery, signage. |
| `scuderia-verde-horizontal.svg` | Horizontal lockup with wordmark + tagline. Use for letterhead, web header, email signature, invoices. |
| `scuderia-verde-monogram.svg` | "SV" disc. Use for favicons, app icons, social avatars, screen-printed touch points (cap, polo, headrest). |
| `preview.html` | Open in a browser to review all marks together. |

## Concept

- **Scuderia** (It. *racing stable*) + **Verde** (It. *green*) — the name nods to
  Italian motorsport heritage, and the brand colour is its identity.
- **Crest format** — borrows from the *scuderia* tradition of heraldic shields
  (Ferrari, Alfa, Maserati). It signals provenance, craftsmanship, and a member
  badge for owners.
- **Steering-wheel ring** around the SV monogram is the racing cue, with a
  single 12 o'clock marker — the gesture every driver makes before a lap.
- **Southern Cross** above the monogram is the only Australia signal, kept
  small and constellation-correct so it reads as place, not flag.
- **Chequered bar** is the finish-line motif, sized as a ribbon under the mark.
- **Typography** — Trajan / Cinzel-class Roman caps for *scuderia* gravitas;
  italic for *Verde* to introduce motion.

## Usage notes

- **Minimum size** — monogram down to 24 px; crest no smaller than 48 px tall
  (the Southern Cross and chequered bar lose legibility below that).
- **Clear space** — pad by the height of the "S" in the wordmark on every side.
- **Reverse** — on dark grounds, render gold-on-verde as drawn. Avoid placing
  the gold gradient on bright/saturated backgrounds; it muddies.
- **Do not** recolour the verde to a brighter green, add drop shadows, or
  reflow the wordmark vertically.
